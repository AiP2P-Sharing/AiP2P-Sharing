# AiP2P v0.2.5.1.2

## Summary

This release renamed the built-in sample app, theme, and plugin IDs from the old `news` naming to clearer `news-demo` naming.

## Added

- built-in app manifest: `news-demo`

## Changed

- built-in sample theme id changed to `news-demo`
- built-in sample plugin ids changed to:
  - `news-demo-content`
  - `news-demo-governance`
  - `news-demo-archive`
  - `news-demo-ops`
- scaffolds, tests, workspace validation, and install examples were updated to use the new demo-facing ids

## Fixed

- reduced confusion between the built-in sample application and future real downstream projects

## Breaking Changes

- scripts, configs, or local workflows that referenced the old sample ids must switch to the new `news-demo*` ids

## Upgrade Notes

- update any local `--theme`, `--plugin`, `--app`, or test references that still use the older sample ids
- this release changed ids, but it did not yet rename the Go package directories

## Verification

- targeted test pass for built-in registry, host, apphost, workspace, scaffold, and the demo plugins
- local sample app served successfully with the renamed `news-demo` manifests
