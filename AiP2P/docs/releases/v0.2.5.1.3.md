# AiP2P v0.2.5.1.3

## Summary

This release finished the `news-demo` rename by changing the actual demo plugin and theme directories, while also restoring the expected sidebar links and simplifying the left-side network dashboard.

## Added

- formal directory-based naming for the built-in demo theme and plugins:
  - `internal/themes/newsdemo`
  - `internal/plugins/newsdemo`
  - `internal/plugins/newsdemocontent`
  - `internal/plugins/newsdemoarchive`
  - `internal/plugins/newsdemogovernance`
  - `internal/plugins/newsdemoops`
- this `docs/releases/` release-history directory

## Changed

- the left sidebar now restores the expected links:
  - `Network`
  - `Policy`
  - `Archive`
- the left-side network dashboard now shows only:
  - `Overall`
  - `Network`
- README, install docs, and the bootstrap skill now point to `v0.2.5.1.3`

## Fixed

- GitHub source tree now matches the public `news-demo` naming instead of keeping old directory names behind renamed manifests
- the sample UI is closer to the older `aip2p-news` navigation layout

## Breaking Changes

- any local imports, scripts, or tooling that referenced the old Go package directories must switch to the new `newsdemo*` package paths

## Upgrade Notes

- use the new `newsdemo*` package paths if you import internal demo packages during local development
- public release history is now tracked in `docs/releases/` and should be updated together with future GitHub releases
